routine-uploader

routine-uploader は、運営者本人が、自分の YouTube チャンネルに自分で作った動画を投稿するためだけに使う、個人用のツールです。

このツールがすること

  • 運営者本人の PC 上で動き、YouTube Data API（YouTube API サービス）を使って、運営者本人のチャンネルに動画をアップロードします。
  • アップロードした動画のタイトル・説明・タグ・カテゴリ・公開設定（非公開・予約公開など）・サムネイル・各種申告（子ども向けかどうか、AI 生成コンテンツかどうか等）を設定します。
  • 投稿先のチャンネルが正しいか、アップロードした動画の状態（処理状況・公開設定）を確認します。

このツールがしないこと

  • 第三者にサービスとして提供していません。利用者は運営者本人のみで、一般の方がログインしたり登録したりする機能はありません。
  • コメント・評価・登録者・アナリティクスなど、上に書いた以外のデータは読み取りません。
  • 取得したデータを広告・販売・AI の学習などに使うことはありません。

English

routine-uploader is a personal tool used only by its owner to upload the owner's own videos to the owner's own YouTube channels. It runs on the owner's PC and uses the YouTube Data API (YouTube API Services) to upload videos and set their title, description, tags, category, privacy/scheduled publishing, thumbnail and required declarations, and to check the target channel and the status of uploaded videos.

It is not offered to anyone else as a service. It does not read comments, ratings, subscribers or analytics, and it does not use any data for advertising, sale, or AI training.

See the Privacy Policy. By using this tool, users agree to be bound by the YouTube Terms of Service. Google Privacy Policy.
