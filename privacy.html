routine-uploader プライバシーポリシー

最終更新：2026年11月21日

1. このツールについて

routine-uploader（以下「本ツール」）は、運営者本人が、自分の YouTube チャンネルに自分で作った動画を投稿するためだけに使う個人用のツールです。第三者にサービスとして提供していません。利用者は運営者本人のみです。

本ツールは YouTube API サービスを使用しています。 本ツールを使用する場合、YouTube 利用規約に同意したものとみなされます。Google によるデータの扱いについては Google プライバシーポリシーをご覧ください。

2. アクセスする Google ユーザーデータ

本ツールは、Google の OAuth で運営者本人が許可した次の範囲（スコープ）だけを求めます。

  • https://www.googleapis.com/auth/youtube.upload（動画とサムネイルのアップロード）
  • https://www.googleapis.com/auth/youtube.force-ssl（投稿先チャンネルの確認、投稿した動画の状態の確認と設定の修正）

本ツールが実際に読み書きするのは次のものだけです。

  • 読み取り：許可したチャンネルのチャンネル ID とチャンネル名（投稿先が正しいかの確認のため）、本ツールでアップロードした動画の ID・処理状況・公開設定・予約時刻。
  • 書き込み：動画ファイルのアップロード、およびその動画のタイトル・説明・タグ・カテゴリ・言語・公開設定（非公開／予約公開など）・サムネイル・申告項目（子ども向けかどうか、AI などによる改変・合成コンテンツかどうか、有料プロモーションの有無）の設定。

コメント、評価、登録者、アナリティクス、メールアドレス、その他の Google アカウントの情報は読み取りません。

3. データの使い方

上記のデータは、運営者本人のチャンネルに動画を投稿し、投稿が正しくできたかを確認するためだけに使います。広告、販売、プロファイリング、AI や機械学習モデルの学習には使いません。

本ツールによる Google API から受け取った情報の使用と他のアプリへの転送は、Limited Use（使用制限）要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

4. 保存する場所と守り方

  • アクセストークン・リフレッシュトークン（許可の証明）は、運営者本人の PC 内のフォルダにファイルとして保存します。このファイルは公開せず、チャットやメッセージにも貼りません。
  • 投稿の記録（日時、チャンネル名、動画 ID、タイトル、成否）を、運営者本人の PC 内のログファイルに保存します。トークンの中身はログに書きません。
  • 運営者のサーバーやクラウドにはデータを保存しません（運営者はサーバーを持っていません）。

5. 外部への送信・共有

  • トークンは、YouTube API を呼び出すために Google のサーバーへ送る以外、どこにも送信しません。
  • 動画とその設定は、投稿のために YouTube（Google）へ送信します。
  • 運営者は、本人の PC 上の作業を AI アシスタント（Anthropic 社の Claude）で自動化しており、本ツールはそこから起動されることがあります。その場合、本ツールが画面に表示する実行結果（チャンネル名、動画 ID、タイトル、成否）はそのアシスタントにも表示されます。トークンの中身は表示しません。
  • 上記以外の第三者に、データを販売・提供・共有することはありません。

6. 保存期間と削除

  • トークンは、許可が取り消されるか、運営者が本ツールの使用をやめるまで保存します。
  • 許可が取り消された場合、運営者はそれを確認してから7日以内に、PC 内の該当するトークンのファイルを削除します。
  • 投稿の記録（ログ）は運営者の PC 内にあり、運営者がいつでも削除できます。

7. 許可の取り消し方

本ツールへの許可は、いつでも Google のセキュリティ設定ページ（https://security.google.com/settings/security/permissions）で「routine-uploader」のアクセス権を削除することで取り消せます。取り消した時点で、本ツールはそのチャンネルに投稿できなくなります。

8. お問い合わせ

このポリシーや本ツールのデータの扱いについてのご質問・苦情は、運営者（poteb90@gmail.com）までご連絡ください。

9. 変更

本ツールの動作を変える場合（扱うデータが増える場合など）は、先にこのページを更新し、最終更新日を変えます。

English summary

routine-uploader is a personal tool used only by its owner to upload the owner's own videos to the owner's own YouTube channels. It is not offered to anyone else. This tool uses YouTube API Services. By using it, users agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.

  • Scopes: youtube.upload and youtube.force-ssl.
  • Data accessed: the authorized channel's ID and name (to confirm the target channel); the ID, processing status, privacy status and scheduled time of videos uploaded by this tool. It writes only the uploaded videos and their metadata (title, description, tags, category, language, privacy/schedule, thumbnail, and declarations such as made-for-kids, altered/synthetic content and paid promotion). It does not read comments, ratings, subscribers, analytics or email addresses.
  • Use: only to upload the owner's videos and confirm the uploads. Never for advertising, sale, profiling, or training AI/ML models. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Storage: OAuth tokens are stored only as files on the owner's PC; an upload log (time, channel name, video ID, title, result) is kept on the same PC and never contains token values. No server or cloud storage is used.
  • Sharing: tokens are sent only to Google's servers to call the API; videos and metadata are sent to YouTube. The owner automates work on their PC with an AI assistant (Anthropic's Claude), which may launch this tool and see its console output (channel name, video ID, title, result) but not token values. No other sharing.
  • Retention and deletion: tokens are kept until access is revoked or the tool is no longer used; after a revocation, the token file is deleted within 7 days. Logs can be deleted by the owner at any time.
  • Revoking access: https://security.google.com/settings/security/permissions
